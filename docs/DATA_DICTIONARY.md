## How to read this dictionary

| Symbol | Meaning |
|---|---|
| **PK** | Primary key |
| **FK → table(col)** | Foreign key; see the [relationships](#relationships-foreign-keys) section for the constraint name |
| **UQ** | Unique index |
| **IX** | Non-unique (performance) index |
| *not null* | Column is mandatory |
| `default` | Value used when the insert omits the column |

Naming conventions used throughout the schema:

* every table is **plural** and its surrogate key is `<singular>_id`;
* every foreign key column is exactly `<referenced_singular>_id`;
* every table carries `created_at`, and anything mutable carries `updated_at`;
* money is `DECIMAL(12,2)`, percentages are `DECIMAL(5,2)`, and no monetary value is ever a float;
* lifecycle columns are uppercase enumerations (`ACTIVE`, `PENDING`, `PAID`, …) enforced by CHECK constraints.
